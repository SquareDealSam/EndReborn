# Textures

The full set of textures for **The Void-Weaver's Awakening**, authored in Blockbench and
mirrored here for reference/backup. These are the same PNGs the mod ships from
`src/main/resources/assets/voidweaver/textures/`.

- `block/` — blocks (stone families, Chorus wood, ores, flora, …)
- `item/` — items, tools, and armor
- `entity/` — mob and boss textures (`entity/equipment/` holds worn armor layers)
